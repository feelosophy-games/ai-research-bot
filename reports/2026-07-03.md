### [Claude Sonnet 5 출시 — Anthropic](https://www.anthropic.com/news/claude-sonnet-5)
- **요약**: Anthropic이 2026년 6월 30일 Claude Sonnet 5를 공개했다. Opus 4.8과 근접한 성능을 Sonnet 급 가격($2/M 입력, $10/M 출력)에 제공하며, 1M 토큰 컨텍스트 윈도우와 128K 출력을 지원한다. Adaptive Thinking이 기본 활성화되어 복잡한 추론 작업에서 스스로 깊게 생각한다.
- **왜 중요**: 에이전틱 코딩 벤치마크에서 63.2%(Opus 4.8은 69.2%)를 기록, "저렴한 Sonnet으로 Opus급 에이전트"라는 비용 효율 공식이 실현됐다. Sonnet 4.6이 끝내지 못한 복잡한 작업을 Sonnet 5가 완수하는 것이 확인됐다.
- **업무 적용 포인트**: API 기반 코딩 에이전트·자동화 파이프라인에서 Opus 대비 비용을 대폭 절감하면서 품질을 유지할 수 있다. 8월 31일까지 할인 가격이 적용되므로 지금 POC를 진행하기 좋은 시점이다.

### [GPT-5.6 시리즈(Sol / Terra / Luna) 프리뷰 공개 — OpenAI](https://openai.com/index/previewing-gpt-5-6-sol/)
- **요약**: OpenAI가 2026년 6월 26일 GPT-5.6 패밀리를 공개했다. Sol(최고 성능, $5/$30), Terra(균형, $2.5/$15), Luna(저비용, $1/$6) 세 티어로 구성되며, 소프트웨어 엔지니어링·컴퓨터 사용·사이버보안 영역에서 프런티어를 갱신했다고 밝혔다. 현재는 약 20개 신뢰 파트너 기관에 제한 공개 중이며 "수 주 내" 일반 출시 예정이다.
- **왜 중요**: Sol/Terra/Luna라는 영구적인 능력 티어 명칭 도입으로 모델 선택이 단순화됐다. Terra는 GPT-5.5 대비 성능 유사, 가격 2배 저렴 — 실질적인 비용 절감이 가능하다.
- **업무 적용 포인트**: 일반 출시 즉시 Terra로 GPT-5.5 기반 워크플로우를 전환하면 API 비용을 절반으로 줄일 수 있다. 고성능이 필요한 작업은 Sol, 대량 처리에는 Luna를 배분하는 멀티 티어 설계가 유효하다.

### [Gemini 3.5 Flash에 Computer Use 통합 — Google](https://blog.google/innovation-and-ai/models-and-research/gemini-models/introducing-computer-use-gemini-3-5-flash/)
- **요약**: Google이 6월 말 Gemini 3.5 Flash에 컴퓨터 사용(Computer Use) 기능을 기본 내장했다. 브라우저·모바일·데스크톱 환경에서 화면을 보고 추론하며 직접 조작하는 에이전트를 구축할 수 있다. 가격은 $1.50/$9(입력/출력, 백만 토큰당)로 경쟁 모델 대비 약 30% 수준이다.
- **왜 중요**: 기존에는 별도 Computer Use 전용 모델을 써야 했으나 이제 주력 Flash 모델에서 바로 사용 가능하다. Google 측 발표로는 경쟁 프런티어 모델 대비 약 4배 빠른 처리 속도를 자랑한다. 엔터프라이즈용 민감한 작업에 대한 명시적 확인 요구, 프롬프트 인젝션 자동 차단 등 보안 기능도 포함됐다.
- **업무 적용 포인트**: 반복적인 SaaS 조작(데이터 입력, 보고서 추출 등)을 Computer Use 에이전트로 자동화하는 진입 장벽이 크게 낮아졌다. Gemini API + Gemini Enterprise Agent Platform으로 즉시 구축 가능하다.

### [엔터프라이즈 AI 에이전트 ROI 리포트 2026: 평균 171%, 74%가 1년 내 회수](https://onereach.ai/blog/agentic-ai-adoption-rates-roi-market-trends/)
- **요약**: 2026년 기업 AI 에이전트 도입 현황 조사에 따르면 평균 ROI 171%(미국 기업은 192%)를 기록하며, 74%의 기업이 첫 해에 투자를 회수했다. 72%의 기업이 이미 프로덕션 단계에 있으며, 57%가 다단계 에이전트 워크플로우를 운용 중이다. Gartner는 2026년 말까지 엔터프라이즈 애플리케이션의 40%에 태스크 전용 AI 에이전트가 탑재될 것으로 전망했다.
- **왜 중요**: 성공 공식이 명확해졌다: 기존 프로세스에 AI를 덧대지 않고 처음부터 에이전트 기반으로 프로세스를 재설계한 기업이 변혁적 수준의 성과를 거두고 있다.
- **업무 적용 포인트**: 고객 서비스, 청구서 처리, 리드 자격 심사 영역에서 ROI 발현이 가장 빠르다(2주~3개월). 먼저 이 세 영역 중 하나에서 시범 운용 후 확산하는 전략이 유효하다.
