### [GLM-5.3 Flash 오픈소스 출시 — Z.AI (Zhipu AI)](https://www.orcarouter.ai/blog/glm-5-3-flash-vs-deepseek-v4-flash)
- **요약**: 2026년 8월 26일, Z.AI(Zhipu AI)가 GLM-5.3 Flash를 오픈소스(MIT 라이선스)로 공개했다. 18B 활성 파라미터의 네이티브 멀티모달 모델로, 이전 GLM-5.2 대비 코딩 성능이 50% 향상됐다. Hugging Face 가중치는 8월 28일 전후 공개 예정이다.
- **왜 중요**: 독립 인텔리전스 인덱스에서 GLM-5.3 Flash(57점)가 DeepSeek V4 Flash(50점)를 앞서며, MIT 라이선스로 상업적 활용에 제약이 없다. 중국 오픈소스 모델의 프론티어 진입이 가속화되고 있다.
- **업무 적용 포인트**: 무료 오픈소스이므로 온프레미스 코딩 보조 도구, 문서 분석 파이프라인에 즉시 도입 검토 가능. 라이선스 비용 절감 효과가 크다.

### [DeepSeek V4 Flash Vision Exp 출시](https://benchlm.ai/compare/deepseek-v4-flash-0731-vs-glm-5-3-flash)
- **요약**: 2026년 8월 21일, DeepSeek이 V4 Flash Vision Exp를 공개했다. SWE-bench Verified 79.0% 달성, 컨텍스트 1,048,576 토큰, 최대 출력 384K 토큰으로 에이전틱 툴 사용에 최적화된 아키텍처다. 비전 기능은 실험적 빌드로 별도 제공된다.
- **왜 중요**: SWE-bench 79%는 현존 최고 수준의 코드 생성 성능 중 하나로, 자율 소프트웨어 개발 에이전트 구축에 직접 활용 가능한 수치다. 초장문 컨텍스트는 대규모 코드베이스 분석에 유리하다.
- **업무 적용 포인트**: CI/CD 파이프라인에 코드 리뷰·버그 픽스 자동화 에이전트로 통합하거나, 장문 계약서·기술 문서의 자동 분석 워크플로우에 활용 가능.

### [Anthropic, Claude 플랫폼 에이전트 도구 4종 정식 출시(GA)](https://aicatchup.com/news/claude-platform-computer-browser-skills-files-ga)
- **요약**: 2026년 8월 19일, Anthropic이 Computer Use(데스크톱 제어), Browser Use(웹 자동화), Files API, Skills API를 베타에서 정식 출시했다. Computer Use는 이제 턴당 여러 동작을 수행 가능하고, Browser Use는 접근성 트리 기반으로 별도 브라우저 없이 동작한다. 동시에 MCP(Model Context Protocol) 오픈 스펙도 공개됐다.
- **왜 중요**: 에이전트 자동화 스택의 핵심 4가지가 한 번에 프로덕션 레디가 됐다. 기업이 Claude 기반 에이전트를 실서비스에 안정적으로 배포할 수 있는 기반이 마련됐다.
- **업무 적용 포인트**: Browser Use로 웹 리서치·데이터 수집 자동화, Computer Use로 레거시 데스크톱 앱 조작 자동화, Skills API로 반복 작업 프리셋 구축에 즉시 적용 가능.

### [Gemini 3.7 Flash 출시 — 50% 비용 절감, 코딩 16% 향상](https://basic-tutorials.com/news/gemini-3-7-flash-unveiled-new-ai-model-for-coding-and-agents-costs-half-as-much/)
- **요약**: 2026년 8월 13일, Google이 Gemini 3.7 Flash를 출시했다. 이전 모델 대비 절반 가격(입력 $0.75/1M 토큰, 출력 $3.75/1M 토큰, 2026년 12월까지), DeepSWE 코딩 벤치마크 49%→65.3%로 대폭 향상, 초당 340 토큰으로 현존 최고 속도를 기록했다.
- **왜 중요**: 성능 향상과 비용 절감이 동시에 달성됐다는 점이 주목할 만하다. 특히 에이전트 워크플로우와 문서 이해에서 강점을 보이며 실용적 비용 대비 성능이 크게 개선됐다.
- **업무 적용 포인트**: 고빈도 호출이 필요한 배치 처리·자동화 파이프라인에서 비용 절감 효과가 즉각적. 코딩 에이전트와 문서 분석 워크플로우에서 GPT-4o 대비 가격 경쟁력 검토 권장.

### [Meta Muse Glimmer 30B 오픈 가중치 공개](https://www.cnbc.com/2026/08/10/meta-muse-glimmer-open-weight-ai.html)
- **요약**: 2026년 8월 10일, Meta Superintelligence Labs가 Muse Glimmer 30B를 Apache 2.0 라이선스로 공개했다. 24GB VRAM 단일 GPU(고사양 Mac·PC)에서 실행 가능한 멀티모달 에이전틱 모델로, Muse Spark를 증류한 버전이다. Muse Spark 1.2의 오픈 가중치 공개도 약속했다.
- **왜 중요**: 로컬에서 실행 가능한 30B 규모의 에이전틱 모델이 무료 상업 라이선스로 배포됐다. 데이터 프라이버시 요건이 엄격한 기업도 클라우드 없이 온디바이스 에이전트 구축 가능.
- **업무 적용 포인트**: 개인정보·영업 비밀이 포함된 문서 처리에 온프레미스 에이전트로 활용. 고사양 노트북 한 대로 실무 수준 에이전트 시범 도입 가능.
