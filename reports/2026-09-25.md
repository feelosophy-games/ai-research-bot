### [OpenAI, GPT-6 Sol·Luna 출시 — Astra 기술을 저가 티어로 확장](https://www.macrumors.com/2026/09/22/openai-gpt-6-sol-luna/)
- **요약**: OpenAI가 9월 22일 GPT-6 Sol과 GPT-6 Luna를 출시했다. GPT-6 Astra 개발에서 얻은 방법론을 적용해 전문 업무·코딩·사실성·정렬(alignment) 품질을 개선했으며, Sol은 GPT-5.6 Sol 대비 실수를 약 절반으로 줄였다. 가격은 Sol이 입력 $2/출력 $10(백만 토큰 기준), Luna가 $0.10/$0.50으로 전 세대 대비 약 50% 인하됐다.
- **왜 중요**: 고성능 모델의 비용 장벽이 또 한 번 낮아졌다. 특히 Luna는 대용량 처리·반복 작업에 경제성이 높아 스타트업·중소기업도 생산급 AI를 적용하기 쉬워진다.
- **업무 적용 포인트**: 코딩 보조(Codex 업그레이드), 문서 요약·분류 자동화에 Sol/Luna를 기존 Astra 대신 채택하면 동등한 품질에서 비용을 대폭 절감할 수 있다.

### [Alibaba Cloud, 엔터프라이즈 AI 에이전트 플랫폼 AgentCore 발표](https://aibusiness.com/agentic-ai/alibaba-launches-enterprise-ai-agent-platform)
- **요약**: 9월 22일 항저우 클라우드 서밋에서 알리바바 클라우드 CTO 리페이페이가 'Agentic Cloud' 전략과 함께 AgentCore를 공개했다. AgentCore는 AI 에이전트의 빌드·실행·거버넌스를 통합 관리하며, 동반 출시된 Agent Context는 실시간 컨텍스트 및 장기 메모리를 제공해 지식 집약 시나리오에서 토큰 사용량을 최대 67% 절감한다고 밝혔다. 회사 측은 태스크 완수율 99% 향상, TCO 70% 감소를 주장했다.
- **왜 중요**: 모델 API 판매에서 완전 관리형 에이전트 플랫폼으로의 전환을 Alibaba가 선언한 것이다. AWS·Azure·GCP와의 엔터프라이즈 AI 플랫폼 경쟁이 본격화된다.
- **업무 적용 포인트**: Alibaba Cloud 기반 인프라를 쓰는 기업은 AgentCore로 고객 서비스·코딩·데이터 분석 워크플로에 에이전트를 빠르게 파일럿할 수 있다. 거버넌스·보안 컨트롤이 내장되어 있어 IT 승인 절차를 줄일 수 있다.

### [Google, Gemini API에 Antigravity 코딩 에이전트 통합 (antigravity-preview-09-2026)](https://ai.google.dev/gemini-api/docs/models/antigravity-preview-09-2026)
- **요약**: Google이 9월 초 Gemini API 관리형 에이전트를 업데이트하며 Antigravity 코딩 에이전트의 도구와 동작을 Gemini API·AI Studio·Interactions API에 통합했다. 동시에 Files API와 Credentials API가 신규 출시됐다. 이전 버전(antigravity-preview-05-2026)은 10월 5일 종료 예정이다.
- **왜 중요**: 기존에는 독립 IDE였던 Antigravity가 Gemini API 무료 티어 포함 전 플랜에서 사용 가능해졌다. 개발자가 별도 도구 없이 API 호출만으로 코딩 에이전트를 워크플로에 삽입할 수 있게 된다.
- **업무 적용 포인트**: CI/CD 파이프라인, 코드 리뷰 자동화, 개발 보조 챗봇에 Gemini Interactions API를 통해 Antigravity 에이전트를 직접 연결하면 셋업 비용 없이 코딩 자동화를 구현할 수 있다.

### [McKinsey: 집중형 워크플로 AI 투자에서 $1당 $3 수익 — 의료·금융·제조 사례 집계](https://www.swfte.com/blog/enterprise-workflow-automation-2026)
- **요약**: McKinsey 4월 2026 보고서에 따르면 워크플로 중심으로 AI를 집중 투자한 선도 기업들은 $1 투자 대비 $3에 가까운 수익을 내고 있다. 업종별로는 의료(14개월 내 $3.20 회수), 제조(Siemens 다운타임 -45%), 금융(Klarna $6천만 절감), 소프트웨어 개발(3년 ROI 376%)이 두드러진다. 반면 전사적 스케일에서 실제 이익을 내는 기업은 5%에 불과하다.
- **왜 중요**: AI 투자 ROI의 핵심은 기술 자체가 아니라 워크플로 재설계다. 파일럿 단계에서 프로세스 변경 없이 AI만 얹으면 95%의 파일럿이 실패한다는 점이 재확인됐다.
- **업무 적용 포인트**: AI 도입 전 기존 프로세스 매핑 → 병목 구간 식별 → 해당 구간에 AI 삽입 → KPI 측정 순서로 접근해야 한다. "AI를 쓰고 있다"는 것보다 "어느 단계를 얼마나 단축했나"를 KPI로 설정할 것.
